## How I work

1. **Research:** competitor analysis, user interviews and surveys, domain research such as tax rules and loan types
2. **Scope:** define the MVP, write the PRD, user stories, acceptance criteria and edge cases
3. **Prototype:** validate ideas cheaply with AI-assisted prototypes or a web MVP before committing engineering time
4. **Build:** work with design in Figma and with engineering in sprints, using Jira tickets and backlog grooming
5. **Test:** functional, end-to-end and regression testing, including on BrowserStack
6. **Measure:** activation funnels in Firebase Analytics and daily session reviews in Microsoft Clarity to find friction
